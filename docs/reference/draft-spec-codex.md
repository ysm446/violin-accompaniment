# バイオリン演奏追従伴奏アプリ 仕様書（初期版）

## 1. 概要

PCのマイクでバイオリン演奏を取り込み、あらかじめ読み込んだ楽譜データ上の演奏位置とテンポをリアルタイムに推定する。推定結果に合わせ、伴奏を自然に追従再生するデスクトップアプリケーション。

利用者は自分のテンポでバイオリンを弾き、伴奏は速さの変化に合わせて滑らかに速く・遅くなる。

## 2. 目的

- 一人でのバイオリン練習でも、演奏に追従する伴奏と合わせられるようにする。
- 楽譜上の現在位置を視覚的に把握できるようにする。
- まずは短い曲を対象に、低遅延で安定して動作する試作品を作る。

## 3. 対象環境

| 項目 | 初期仕様 |
| --- | --- |
| 実行環境 | Windows または macOS のPC |
| 入力 | PC接続マイクまたはオーディオインターフェース |
| 出力 | PCスピーカーまたはイヤホン・ヘッドホン |
| 対象楽器 | バイオリン（単音演奏） |
| アプリ形態 | デスクトップアプリ |

## 4. 基本の利用フロー

1. 利用者が楽譜ファイルと伴奏データを選択する。
2. アプリが楽譜を表示し、マイク入力を開始する。
3. 利用者がバイオリンを弾く。
4. アプリが音程と発音時刻を検出する。
5. 楽譜と照合し、現在の小節・拍・テンポを推定する。
6. 推定テンポに合わせて伴奏を再生・調整する。
7. 画面上の楽譜カーソルを現在位置へ移動する。

## 5. 機能要件

### 5.1 楽譜・伴奏の読み込み

- MusicXML形式の楽譜を読み込めること。
- MIDI形式の伴奏を読み込めること。
- 楽譜と伴奏データを曲単位で対応付けられること。

### 5.2 演奏音の検出

- マイクから連続して音声を取得すること。
- バイオリンの主な音程を音名またはMIDIノート番号として検出すること。
- 音の発音時刻を記録すること。
- 短い雑音や一時的な誤検出をできる限り除外すること。

### 5.3 楽譜上の位置推定

- 検出した音程とリズムを、楽譜上の音符列と照合すること。
- 現在の小節・拍・音符位置を推定すること。
- 単一音の一致だけでなく、直前までの音の並びとタイミングを使うこと。
- 軽い音外れや弾き直しがあっても、近い演奏位置へ復帰できること。

### 5.4 テンポ追従伴奏

- 演奏の発音間隔からテンポを推定すること。
- MIDI伴奏を現在位置に合わせて再生すること。
- 演奏テンポの変化に合わせて、伴奏テンポを滑らかに変更すること。
- 伴奏が急激に速く・遅くならないよう、テンポ変更を平滑化すること。
- 音の出力先としてPCスピーカーまたはイヤホンを選べること。

### 5.5 画面表示・操作

- 楽譜または簡易的な音符列を表示すること。
- 推定した現在位置をカーソルなどで表示すること。
- 現在テンポを表示すること。
- 「開始」「停止」「最初から」操作を提供すること。
- マイク入力レベルと認識状況を確認できること。

## 6. 非機能要件

- 演奏入力から伴奏反映までの遅れは、初期目標として体感上不自然でない範囲に抑える。
- 楽譜・伴奏を読み込んだ後は、インターネット接続なしでも動作できる。
- 処理中に画面や伴奏再生が途切れないことを重視する。
- 主要なエラーは、利用者が次に取るべき行動とともに表示する。

## 7. 技術構成案

| 役割 | 初期候補 |
| --- | --- |
| アプリ本体 | Pythonデスクトップアプリ（例: PySide / Qt） |
| マイク入力 | Python音声入出力ライブラリ |
| 音程検出 | 音声解析ライブラリまたは独自の音程推定処理 |
| 楽譜形式 | MusicXML |
| 伴奏形式 | MIDI |
| MIDI音源・再生 | PC上のソフトウェア音源またはMIDI再生エンジン |
| 位置・テンポ推定 | 楽譜の音符列と演奏履歴を照合するロジック |

## 8. 初期試作の範囲（MVP）

初期版では、以下に限定する。

- 1パートのバイオリン旋律と、1つのMIDI伴奏。
- 短い曲、一定拍子、明瞭なテンポの曲。
- 演奏開始位置は曲の先頭。
- 楽譜表示は最小限でよい。
- 大きく前後へ飛ぶ操作や、複雑な繰り返し記号への対応は後回しにする。

## 9. 開発ステップ

1. **音程検出の検証**：マイク入力からバイオリンの音名と発音時刻を取得する。
2. **楽譜照合の検証**：短い音符列に対して、現在位置を推定する。
3. **伴奏再生の検証**：MIDI伴奏を再生し、テンポをリアルタイムに変更する。
4. **追従制御の統合**：位置推定とテンポ推定を伴奏再生へ反映する。
5. **画面化**：楽譜、現在位置、再生操作を追加する。
6. **演奏テスト**：実際のバイオリン演奏で遅延・誤認識・追従感を調整する。

## 10. 今後の拡張候補

- 高品質なピアノ・オーケストラ音源への対応。
- 楽譜の詳細表示とページめくり。
- 任意の小節からの開始。
- 難易度別の追従感度設定。
- 演奏の録音と振り返り。
- 他の単音楽器への対応。

## 11. 主なリスクと対応方針

| リスク | 対応方針 |
| --- | --- |
| 弓のノイズや周囲の音で誤認識する | 音量・継続時間・直前の演奏履歴を使って判定を安定化する |
| 同じ音が繰り返され、楽譜位置を誤る | 音程だけでなく、リズムと前後の音の並びも照合する |
| テンポ変更が不自然になる | 変化量を平滑化し、伴奏テンポを徐々に追従させる |
| PC環境により音の遅れが異なる | 音声バッファ設定と出力デバイスを調整できるようにする |
