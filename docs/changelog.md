## 未リリース

### 2026-08-30 15:40 — 追従の複数仮説化

- 追従器が「いま追いかけている位置」のほかに、楽譜上の別の候補(副仮説)を並走させ、副仮説のほうが良い状態が一定時間(近くなら 1.5 秒、遠くなら 4 秒)続いたときだけ乗り換えるようにした。ミスや過渡など一瞬の差では飛ばず、同じ楽句のコピーが並ぶときは現在位置に近いほうを採る。春を 4 分通した記録で、平均のずれが 13.7 秒 → 1.5 秒。
- 状態に `alternates`(副仮説の位置とリード秒数)を追加(UI 表示は未対応)。

### 2026-08-30 14:40 — 伴奏のフェードイン / アウト、メトロノーム

- 追従モードの伴奏は 1 秒のフェードインで入り、止まるときは 0.3 秒のフェードアウト(CC11 エクスプレッション)。
- 音量スライダー(伴奏 🔊 / メトロノーム ♩🔊)を追加。値はブラウザに記憶され、次回起動時も反映される。
- 「♩ メトロノーム」トグルを追加。拍子に合わせてクリック(小節頭はアクセント、12/8 などの複合拍子は付点四分で刻む、弱起は最初の小節頭から)。通常再生・追従のどちらでも鳴る。

### 2026-08-30 14:05 — 長い演奏での追従の崩壊を軽減、楽譜を 3 曲追加

- 追従 ON で 4 分ほど通して弾いた記録で、途中から位置を見失って戻れない問題(変更前からあった)を軽減。速い 16 分音符の楽句で「楽譜のオンセットが音に無い」ペナルティが積み上がって別区間に負けるのをやめ、直近 1〜2 秒だけ別の場所が合っていても乗り換えないよう記憶を長くした。春の 254 秒の記録で、外れている 10 秒区間が 26 中 19 → 12。
- 楽譜に「戦場のメリークリスマス」「energy flow」「ヴィヴァルディ『夏』第3楽章」を追加(曲選択に出る)。

### 2026-08-30 12:50 — 同音連打の追従(Phase 5)

- 同じ音の連打(春の B5 ×21 など)で伴奏が数秒遅れなくなった。合成演奏の評価で連打区間の誤差 中央値 543 → 22 ms、p95 3199 → 59 ms。
- 弾き直し・途中開始からの復帰が速くなった(1.5 秒の無音のあとの再アンカー 2.5 → 1.0 秒)。
- 楽譜の休符を奏者が長めに取っても、休符の終わりで待つ(休符の長さ + 1 秒までは見失いにならない)。
- 誤った場所へ遠くジャンプしにくくした: 候補が 1 箇所に絞れているときだけ飛び、複数なら再探索して待つ。
- 追従器の回帰テスト(`core/tests/test_follower.py`)を追加。

### 安定性・安全性の修正

- 追従 ON 中は確実性の開始条件を通った場合だけ伴奏を開始し、通常の再生・シーク・レート操作で条件を迂回できないようにした。
- 停止・シークと MIDI イベント送信の競合を解消し、停止後に古い note-on が送られて音が残る問題を防止した。
- リアルタイム音声キューの最大滞留を約 85 ms に制限し、入力切り替え後に旧入力のブロックが混ざらないようにした。
- WebSocket の接続元を Electron と localhost の開発 UI に制限し、解析対象のセッション ID が記録フォルダ外を参照できないようにした。
- 録音セッション名をマイクロ秒まで含む形式にし、素早い録音再開による上書きを防止した。
- core の回帰テストを追加し、追従評価スクリプトの壊れていた `--trace2` と未使用パラメータ表示を修正した。

### 2026-08-30 15:00 — 確実になってから追従

- 追従モードの伴奏は、楽譜上の位置が一意に確定して 1 秒安定してから始まる。曖昧な間(同じ楽句が複数箇所にある等)は鳴らさずに聞き続け、状態を「聞いています(候補 n 箇所)」と表示。
- 追従中に位置が大きくずれたら、飛びつかずに伴奏を止めて確認し直す。

### 2026-08-30 14:00 — 好きな場所から弾ける追従

- 追従モードで、音が無ければ伴奏を弾かない(1 秒無音で停止。楽譜上の休符なら待つ)。弾き始めると楽譜全体から位置を探して伴奏を再開する。
- 状態表示(待機中 / 追従中)を追加。

### 2026-08-30 13:00 — 追従の落ち着き

- 追従モードの伴奏が頻繁に飛ばないように: 弾き始めて少し待ってから開始、ずれが続いたときだけシーク、シーク後しばらくは再シークしない。

### 2026-08-30 12:00 — Phase 3: オンライン追従

- 演奏をリアルタイムに楽譜と照合する追従器を追加(`violin_core.follower`)。
- ツールバーに「◎ 追従」ボタン。ON にすると青いカーソルが演奏位置を示し、伴奏が演奏に同期する(誤差が大きいときはシーク、小さいときはテンポを緩やかに合わせる)。「最初から」で追従器もリセット。
- 追従器の評価スクリプト `core/tools/eval_follower.py`。

### 2026-08-30 09:30 — Phase 2: 演奏後フィードバック

- 記録したセッションを楽譜と DTW で整列し、音符ごとの音程偏差(セント)とタイミング偏差(ms)を計算(`violin_core.align`)。
- UI に「振り返り」バーを追加。記録を選んで「解析」すると譜面上にマーカーが出る(色 = 音程、バー = 早い/遅い、ホバーで詳細)。
- 評価用に正解つき合成演奏の生成(`violin_core.synth`)を追加。

### 2026-08-30 07:30 — Phase 1: 音声入力とリプレイ基盤

- UI に入力デバイス選択、レベルメータ、chroma バー、遅延表示、記録開始/停止ボタンを追加。
- セッション記録(音声 WAV・特徴量・再生位置)と、記録をオフラインで再処理する `violin_core.replay` を追加。`--input-wav` で WAV をマイク代わりに流せる。
