# goals — プロジェクトの目的と完成形

作成日時: 2026-08-30 02:52
更新日時: 2026-08-30 14:00

## 目的

一人でのバイオリン練習で、演奏に追従してくれる伴奏と合わせられるようにする。演奏者が自分のテンポで弾き、伴奏がそれに合わせて滑らかに速く・遅くなる。

## 完成形

- MusicXML の楽譜と MIDI の伴奏を読み込み、譜面を表示する。
- マイクまたはライン入力からバイオリンの演奏を取り込み、楽譜上の現在位置とテンポをリアルタイムに推定する。
- 推定に合わせて MIDI 伴奏を再生し、譜面上のカーソルが現在位置を追従する。
- 軽い音外れ、弾き直し、停止があっても追従を失わず、失った場合も数秒で復帰する。
- 通し演奏を前提にしない。曲の好きな場所を弾き始めればそこから伴奏がつき、弾くのをやめれば伴奏も止まる(練習の使い方に合わせる)。
- 演奏後に、音符ごとの音程偏差・タイミング偏差を譜面上で振り返れる。

## 重視する価値

1. **追従の安定性**: 見失わないこと、伴奏が暴走しないこと。精度より先に「気持ち悪くならない」こと。
2. **再現性のある開発**: 録音とリプレイで追従器を評価できること。毎回弾いて調整する運用にしない。
3. **差し替え可能な構成**: `{position, tempo, confidence}` の 3 値を唯一の共有インターフェースにし、追従器や実装言語を後から置き換えられること。
4. **練習の道具であること**: 演奏後フィードバックのように、追従が完成する前から練習に役立つ機能を優先する。

## 対象と前提(初期)

- 対象楽器: バイオリン、単旋律。重音は破綻させないことを目標にするが精度保証外。
- 入力: 電子バイオリンのライン出力、またはマイク。マイク時はヘッドホン運用を推奨し、伴奏の回り込みを前提から外す。
- 楽譜: 事前に指定する。曲の自動識別はしない。反復記号を含む楽譜は初期は対象外。
- 動作環境: Windows / macOS のデスクトップ。読み込み後はオフラインで動作する。

## スコープ外(将来)

- オーディオ録音伴奏のタイムストレッチ
- ゲームモード(採点)
- 反復記号・D.C. の自動展開
- スピーカー運用時の回り込み対策
